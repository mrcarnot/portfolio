# Personal Portfolio II (CS344 Web Engineering - Lab 3)

Multi-page personal portfolio built with plain HTML and CSS (no JavaScript, no frameworks).

- `css/style.css` - single external stylesheet (float / clear layouts, horizontal nav)
- `images/` - profile photo and gallery images
- Pages: `index.html`, `gallery.html`, `skills.html`, `contact.html`, `hobbies.html`
